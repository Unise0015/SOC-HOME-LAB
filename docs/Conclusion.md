# Conclusion

This project provided practical experience with both offensive and defensive sides of cybersecurity operations. It covered SIEM configuration, endpoint telemetry collection, network intrusion detection, and basic incident response workflows.

Building and operating the lab reinforced how SOC tools work together in practice—from log ingestion and alert generation to triage and correlation. It also made clear how much of SOC work is iterative tuning and troubleshooting rather than one-time setup.
