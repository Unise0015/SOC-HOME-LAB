# Recommendations

1. Tighten pfSense firewall rules to limit unnecessary traffic between segments.
2. Expand Snort IDS rulesets to cover additional attack patterns beyond the defaults.
3. Add automated IP blocking for addresses flagged by Snort alerts.
4. Enable multi-factor authentication on management interfaces (Splunk, pfSense).
5. Continue refining log forwarding pipelines and alert thresholds to reduce false positives.
